## Unit GENERATION (level id = generation)
Owns generation facts and body/chassis knowledge: `gen.identity` (start/end year of the whole production run), `gen.facelift` (year, or a check `N/A`), `gen.recalls` (KBA / manufacturer recall search; each recall its own `reliability(..., recall=True)` row with its build window `applies_from`/`applies_to` and an `inspection_action` "dealer VIN check"), `gen.baseline` (if neither the TÜV-Report nor the ADAC Pannenstatistik has a readable figure for THIS generation after you tried both, record `check('generation', {LEVEL_ID}, 'gen.baseline', source_id, 'N/A')` with the sources tried and the reason in the note, and stop: never use another model's figures as a proxy, and never leave the item open because a figure is unreadable; otherwise TÜV/ADAC `reliability_stats` per age class with the class average, or check `N/A`; on disagreement write the less favourable figure, quote the other in `notes`, raise a `SOURCES_DISAGREE` flag), `gen.safety` (Euro NCAP `ncap_stars`, `ncap_year`, or check `N/A`), `gen.risks` (body/chassis faults, each priced, or a check `NONE FOUND`), `bdy.risks` (body style faults), and the checks `rel.<PART>.adac|tuev|guide` for ENGINE, GEARBOX, CHASSIS and ELECTRICS (`check('generation', {LEVEL_ID}, 'rel.<PART>.<adac|tuev|guide>', source_id, 'FOUND' | 'NONE FOUND')`).
Start: `todo(vehicle_id=<a variant of this generation>)` (the listing's variant: `listing({LISTING_ID})`) and `GET /api/generations`. Protocol: step 2 (reliability: ADAC, TÜV-Report and a buying guide for every part), step 5 (faults), "Phase windows" (a fault fixed by the facelift or a recall build range uses `applies_from`/`applies_to`, never a second generation). Weak points via `reliability(...)` with `part=` (ENGINE / GEARBOX / CHASSIS / ELECTRICS), or `fault(..., level='generation')` for a defect with a frequency and a price; one row per distinct failure; generic wear is a priced risk, not a weak point. Every risk is priced (`ESTIMATED` with the derivation when nothing better exists).
No browser. Last line: `CARLOS_RESULT done: <summary>` or `CARLOS_RESULT failed: <reason>`.
