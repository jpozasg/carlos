## Unit CAPTURE: read the listing and write it
Owns `lst.capture` and `lst.photos`. Browser: Claude in Chrome, a new tab of your own, closed at the end. No browser, or several connected and none selected: do not pick one, end `CARLOS_RESULT failed: browser unavailable (<what the tool said>)`.

1. Read `docs/browser-tasks.md`. If the URL is `carlos://listing/<id>` (or a listing of this account without a variant): `GET /api/listings/<id>`; if its ad is still online re-capture it; if offline, the reference car, or stored-only, do not fail: attach the variant with `PATCH /api/agent/listings/<id> {"vehicle_id": ...}` when the stored HSN/TSN allow it, log a `verification` entry ("ad offline / own car: researched from the stored capture") and end `CARLOS_RESULT listing_id=<id>`.
2. **The shell first.** `capture_listing.py` needs a `vehicle_id`, and the catalogue may be empty. From what the ad states (never guess; the VARIANT unit completes and corrects it later) find or create the three rows with the helpers: `GET /api/vehicles` (a variant with the ad's HSN/TSN: `POST /api/agent/vehicles` with that `hsn`/`tsn` reuses it), else `generation(make=..., model=..., name=<generation, e.g. 'Mk7 (2012-2020)'>, start_year=..., end_year=...)` (reuse an existing one from `GET /api/generations`), `engine(code=<engine code or the power class, e.g. '1.2 PureTech 82'>, fuel_type=..., displacement_cc=..., power_kw=..., power_ps=...)` (reuse from `GET /api/engines`), and `python3 -c "from agent_tools import *; print(post('vehicles', {'generation_id': G, 'engine_id': E, 'trim': ..., 'hsn': ..., 'tsn': ..., 'transmission': ..., 'body_style': ...}))"` (omit hsn/tsn when the ad does not show them). Put that `vehicle_id` in the capture JSON.
3. Otherwise read the page, write a capture JSON in your scratchpad, run `python3 capture_listing.py <capture.json> --dry-run`, then for real. It writes source, listing, capture, photos, checklist and the `found` log entry; a known HSN/TSN reuses the shared catalogue variant (step 2). Structured facts as the ad states them (null when not shown, never guessed): `seller_type` DEALER/PRIVATE, `warranty` 1/0, `hu_until` YYYY-MM, `service_history` YES/CLAIMED/NO, `accident_free` YES/CLAIMED/NO, `postal_code`, and for a dealer ad always `seller_rating` and `seller_reviews`. Electric car: the seller's battery-health figure goes in `battery_soh_claim`. Photos the script skips: fetch through the browser or report them.
4. **Out of scope (#165):** a new car (no first registration, delivery km only) or a lease-only ad is not captured: end `CARLOS_RESULT failed: out of scope: new car / lease-only ad (second-hand purchases only, #165)`. A used ad that also shows a lease rate is captured as a purchase.
5. Listing unreadable (blocked, login, CAPTCHA): stop and `CARLOS_RESULT failed: <reason>`.

Do no research beyond the capture. Last line: `CARLOS_RESULT listing_id=<the listing id>` or `CARLOS_RESULT failed: <reason>`.
